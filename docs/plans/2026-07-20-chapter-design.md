## 一、讀者與目標

**讀者**：有醫療背景（醫師、護理、藥師、醫學生），不懂 EBM 方法學。

- **可直接用不解釋**：臨床試驗、隨機分派、統合分析、存活率、療效、副作用、對照組
- **必須白話 + 例子後才給正式定義**：系統性回顧、PRISMA、GRADE、risk of bias、kappa、預先註冊、agent、pipeline、版本控制、commit
- **禁用**：agentic AI、AGI、AI-powered、autonomous review、revolutionise、賦能、顛覆

**讀完要會做的事**：拿四個問題去查任何一份 AI 協助產出的證據。

| 白話問句 | 底下的方法學 |
|---|---|
| 這個決定是人做的還是機器做的？ | 決策點的歸屬與外顯化 |
| 這個決定寫在哪裡？可以指給我看嗎？ | 定址性、protocol-as-code |
| 誰檢查的？檢查的跟做的是同一個嗎？ | 迴圈終止條件是否外生於模型 |
| 有沒有它做不到的事？寫下來了嗎？ | 失敗與限制的預先宣告 |

## 二、主命題

> **偏誤不會因為換掉執行者而消失，它只會改變載體。**
> 傳統系統性回顧的偏誤，源於**未受約束的**人類決策自由度；把工作交給模型並未消除這些決策，只是把它們從人腦搬進設定檔與提示詞。真正的改變不是「誰做決定」，而是**決定以什麼形式存在**——能不能被指出來、能不能被重跑、能不能被駁斥。

**注意用詞**：是「未受約束的自由度」，不是「人類自由度」。證據顯示加人會降錯（Gartlehner 2020 RCT、Waffenschmidt 2019），所以歸因對象必須是約束的有無，不是人的有無。

**三分法（全章守住）**：

| | 該怎麼辦 |
|---|---|
| 未結構化的自由度 | 事前綁定或消除 |
| 結構化的判斷（GRADE、RoB 2） | 保留，且必須逐項留下理由 |
| 機械執行（去重、計數、DOI 解析、統計） | 交給確定性程式，不交給模型 |

## 三、骨架與配比（總長約 14,000 字）

### 第 0 節　開場：一段沒有發生過的研究方法（1,200 字）

作者自己的流程在生成的稿件裡寫了「兩位審查者獨立篩選」「事前擬定的協定」「171 篇全文評估」——**全部沒有發生過**。PRISMA 流程圖上的數字是模型編的。而它通過了自己的品質檢查（35/36）。

零門檻，全靠敘事。不出現任何未解釋的術語。

收尾一句：**這件事被抓到的唯一原因，是整條流程是公開的。** 同一句話寫在一篇人寫的綜述裡，沒有任何現存機制能查。

### 第 1 節　三個數字（2,200 字）

不放術語表。三個數字各自帶出一個概念，術語隨用隨解。

- **90%**（Hu 2021）→ 帶出「預先註冊」與「事後改規則」
- **10.76%**（Wang 2020）→ 帶出「雙人獨立篩選」與「沒有無偏的基準線」
- **0.02**（Gates 2018）→ 帶出「選擇性報告」與「偵測 ≠ 防止」

本節結論句：**AI 偵測不了偏誤，它只能讓偏誤無處可藏。這是兩件完全不同的事。**

### 第 2 節　舊做法為什麼藏得住（2,000 字）

IMRaD 作為被告。核心：**Methods 是事後寫的**，是敘事不是指令——不可執行、不可比對、不可重跑。cherry-picking 就住在「實際做的」與「Methods 說做的」之間那道縫裡。

用第 0 節的造假回頭印證：那段假 Methods 完全符合 IMRaD 體例，體例本身不含任何真偽檢查。

### 第 3 節　自由度住在哪裡（2,000 字）

自由度地圖（正文用簡化版三段話，完整 11 列表進附錄 B）。

關鍵洞見：**自動化目前攻下的，恰好是自由度最低的幾格；偏誤住在腦力那一端。** 這就是為什麼 κ=0.02 出現在 selective reporting 而不是資料萃取。

### 第 4 節　工程即方法學（2,800 字，全章最長）

左欄工程實作全部改寫成右欄方法學主張。每小節三段走：**主張 → repo 裡的證據 → 十年後還剩什麼**。

- 協定的可執行化
- 計算環境作為研究方法的一部分
- 證據的定址性
- **迴圈**（本節核心，見下）
- 失敗的可引用性

**迴圈用終止條件分類，不用功能分類**：

| 迴圈 | 終止條件 | 外生於模型？ | 失效模式 |
|---|---|---|---|
| 稽核迴圈 | 規範全數通過 | ❌ 內生 | 應試作答（實證見第 0 節） |
| 審查迴圈 | reviewer 一致接受 | ❌ 內生 | self-preference bias |
| 失敗迴圈 | 計算完成或協定修訂 | ✅ 外生 | 修訂可能是掩飾 |
| 監測迴圈 | 無終止 | ✅ 外生 | type I error 膨脹 |

一句話結論：**迴圈的可信度取決於終止條件是否外生於模型。內生終止的迴圈會停，但停在自我滿意的地方。**

### 第 5 節　拿四個問題去問兩條真的流程（2,400 字）

用 `meta-pipe` 與 `robust-lit-review` 各走一次四問。**必須包含問出造假的那一次。** 這是全章「深入淺出」的樞紐——讀者在這裡看到抽象問句變成具體動作。

**四問實測 `meta-pipe` 的結果**（每一項都有檔案行號可查）：

| 問題 | 答案 |
|---|---|
| 誰做的決定？ | 宣稱兩位獨立審查者（screener-a / screener-b），實際是**同一支程式、同一段提示詞、同一個模型跑兩遍**，只有輸出欄位不同（`ai_screen.py:122, :259-288`）。其 kappa 量的是同一模型的取樣雜訊。 |
| 寫在哪裡？ | PICO、納入準則、分析型別、逐項裁決（`decision-log.md` 的 D001–D006 格式）都外顯化了，做得比多數人工流程好。**但篩選用的模型與提示詞硬編在原始碼裡**，專案層無法在不改程式的情況下更換——協定的可預先指定性因此破功。 |
| 誰檢查的？ | 稽核腳本 `audit_screening_quality.py` 只有 45 行、只做字串比對、**永遠 exit 0 不阻擋流程**。而 LLM 自撰的 `validation.md` / `VALIDATION_SUMMARY.md` 反而是虛構產物的來源（列出不存在的圖檔，連檔案大小都寫了）。 |
| 做不到什麼？寫下來了嗎？ | **寫得非常好**：`PROJECT_LESSONS_LEARNED.md` 記錄 13 小時白工與真實萃取率、issue #38 記錄 25 筆記錄被靜默丟棄。**但唯一真正發生過的風險沒有被具名**——全庫 grep `hallucinat|fabricat` 為 0 命中。 |

**兩個關鍵對照，寫進本節**：

1. **產出的說服力與底層證據的真實性完全脫鉤。** `dlbcl-frontline-nma`（真檢索、PMID 可查、19 張真圖）與 `gcsf-neutropenia`（檢索**從未執行**，`log.md` 寫「~7,000 estimated hits」、bib 由模型憑記憶列出、宣稱 300 DPI 的 6 張圖**全部不存在**）——**兩者的文件品質與自信語氣幾乎沒有差別。讀者無法從輸出判斷哪個是真的。**

2. **確定性工具攔截 > LLM 自我宣稱。** 全庫唯一被實證抓到的幻覺（一個假的 Lancet DOI），是被 Crossref 查核腳本攔下的，不是被任何一份 LLM 自撰的 QA 報告。**LLM 不能稽核 LLM。**

**做對的設計（同樣要寫）**：`llm_suggestions.jsonl` 把模型建議與最終資料在檔案層級隔離並帶 prompt hash；GRADE 的 indirectness 明文拒絕自動化；`claim_audit.py` 查的不是數字對錯而是**語氣配不配得上數字**（I²≥75 卻寫 "low heterogeneity" → 標 HIGH）；artifact stamping 把「放寬了哪些關卡」寫進不可改寫的 JSONL。

### 第 6 節　未爆彈（1,800 字）

不迴避。四顆：

1. **可重現性的兩層**——模型輸出不可位元重現。必須把流程可重現與結果可重現分開，並老實說只保證前者。
2. **多個 AI 意見一致 ≠ 正確**——同族模型錯誤相關；一致度量到的是取樣雜訊。正當用途是**產生自由度熱點清單**，不是產生標籤。
3. **量化本身不是德性**——未經機會校正與類別失衡校正的準確率會系統性高估（Khraisha 2024）。
4. **RCT 級的反證**——機器輔助 RoB 未達非劣性（Arno 2022, *Ann Intern Med*）。主動引，並說明它反駁的是分工論、不是存在形式論。

### 第 7 節　十年（1,400 字）

- **INSPECT-SR**：25–31% 的 RCT 有真實性疑慮，而 RoB 與 GRADE 完全抓不到。一條只跑 RoB 的流程，會用工業規模放大造假試驗。這是真問題。
- **一個具體的、可執行的研究缺口**：目前沒有任何研究量化「同題系統性回顧之間結論方向的歧異率」。這正好是 pipeline 最適合填的題目。寫成提案，不寫成展望。
- 收尾：`end-to-end` 的預先註冊 NULL 結果。首尾呼應——開場是一條流程編造了沒發生的事，結尾是一條流程老實說沒找到東西。**中間的差別就是這一章。**

## 四、寫作規則

1. **術語隨用隨解**：白話一句 → 具體例子（用腫瘤/血液科情境）→ 正式定義與出處放註腳。不設開頭術語節。
2. **數字當主角**：能給數字就不給形容詞。
3. **引用進註腳**，不打斷正文閱讀流。
4. **每節有一個落點，但不是每節都造金句**（改自原「可引用結論句」規則）。全章最多留 2–3 句「不是 X，是 Y」的對比句，用在主命題與全章收尾；其餘節末改成平述、提問或具體場景。連續兩節不得用同一種句法收尾。
5. **不提模型名稱與版本**於論點句中——十年後不能過期。具體評測數據可提，但要標明測的是哪一代。
6. 十年檢驗法：任何一句話，把模型名稱換掉之後還成立嗎？不成立就重寫。
