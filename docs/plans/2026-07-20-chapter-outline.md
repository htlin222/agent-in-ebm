# 章節正式架構（段落級・10,000 字版）

**用法**：每個 `¶` 是一個段落。`重點` = 該段唯一要說的事；`論點` = 它在 `argument/chapter-thesis.argdown` 上對應的節點；`引用` = 已驗證的出處；`字` = 目標字數。
**未標「已驗證」的引用不得寫入書稿**，見文末待查清單。
**讀者**：有醫療背景、不懂 EBM 方法學。臨床名詞可直接用；方法學名詞一律「白話→例子→註腳定義」。
**字數硬上限**：正文 10,000 字（附錄不計入）。本版由 19,300 字版壓縮而來，壓縮原則：論證主脊全保留，砍重複、次要引用、術語鋪陳。

# 第 3 節　自由度住在哪裡
